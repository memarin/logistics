# Project Instructions

## Implementation workspace

- Use an isolated Git worktree on a dedicated feature branch for implementation.
- This instruction grants standing consent to create worktrees.
- Reuse an existing isolated worktree when appropriate.
- Prefer native worktree tools; otherwise use git worktree.
- Use .worktrees/ and make sure Git ignores that directory.
- Do not implement directly on main or master.
- If worktree creation fails, report the blocker instead of working on main.
- Commit, merge, push, and deploy only when explicitly requested.
